# User Guide

Back to the [README](../README.md).

## Opening files

Double-click any `.md` file in Finder. Folio opens it in a tab.

## Reading

Folio remembers where you were. Scroll down, close the tab, and reopen it.

```python
def fib(n: int) -> int:
    """Return the n-th Fibonacci number."""
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```
